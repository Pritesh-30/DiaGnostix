How the prediction works.

The model

DiaGnostix uses a Support Vector Machine (RBF kernel) trained on the NHANES 2021–2023 survey dataset (~6,000 US adults). Each input passes through the same pipeline used in training:

  1. Outlier capping — extreme values are clipped to the 1.5×IQR range of the training data.
  2. Median imputation — fills any missing values.
  3. Standard scaling — puts every feature on the same scale.
  4. SVM classification — outputs a diabetic / non-diabetic class and a probability.
